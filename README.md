# Papercut releases

Installers and automatic updates for **Papercut**, a paper-cut tool for documentary editors
that works alongside DaVinci Resolve Studio. The source code is private; this repository only
holds releases.

## Install

1. Download the latest `Papercut_<version>_aarch64.dmg` from [Releases](../../releases/latest).
2. Open it and drag **Papercut** into Applications.
3. First launch: if macOS says it can't check the app, go to **System Settings › Privacy &
   Security** and click **Open Anyway** (once).

Requires an Apple Silicon Mac (macOS 13+) and DaVinci Resolve Studio 21 with
*Preferences › System › General › External scripting using* set to **Local**.

## Updates

Papercut updates itself. When a new version is published here, the app shows
**Restart to update**. Updates are signed; the app only installs ones signed by the
Papercut release key.
